# Cozy Way Homestay Website

Cozy Way is a modern React + Vite website for a homestay in Dharamshala, Himachal Pradesh.  
It highlights rooms, gallery images, nearby places, testimonials, contact details, and legal pages, with an admin area for managing site content.

## Live Site

- https://www.cozyway.in/

## Features

- Responsive multi-page experience using React Router
- Home, About, Rooms, Gallery, Nearby Spots, Contact, Testimonials
- Admin dashboard and content management sections
- SEO-ready metadata, Open Graph tags, sitemap, and robots config
- Smooth UI transitions and reusable component system

## Tech Stack

- React 18
- Vite
- Tailwind CSS
- Radix UI
- Framer Motion
- Supabase

## Getting Started

### 1. Clone the repository

```bash
git clone <your-repo-url>
cd cozywayfinal
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run development server

```bash
npm run dev
```

App runs at `http://localhost:3000`.

## Build for Production

```bash
npm run build
```

## Preview Production Build

```bash
npm run preview
```

## SEO Notes

- Canonical URL configured in `index.html`
